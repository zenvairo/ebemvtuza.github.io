# EVT corp. guides

Static local prototype for the five requested routes. Open `index.html` directly or serve the folder with any static HTTP server.

The visual layer is shared through `styles.css`; the page content is kept in each route's HTML so the text can be replaced without touching the layout.

Routes:

- `/` -> `https://hive-squad.github.io/`
- `/start/` -> `https://hive-squad.github.io/start/`
- `/models/` -> `https://hive-squad.github.io/models/`
- `/tiktok/` -> `https://hive-squad.github.io/tiktok/`
- `/teamlead/` -> `https://tvtvvsttvtvtaa-dev.github.io/TeamLead-guide/`

The current route copy is a fallback because the source domains were unreachable from the build environment. See `design-qa.md` for the verification status.
