EVT corp./start

Start

Первый запуск

Базовый порядок действий для входа в рабочий контекст.

Начни с одного маршрута. Пройди шаги по порядку и зафиксируй результат.

Контекст

Проверь доступ к материалам, цель текущего цикла и выбранный приоритет.

Шаги

  1. Открой актуальный документ и прочитай вводную.
  2. Собери вопросы в одном месте.
  3. Сделай первый проход и зафиксируй результат.
  4. Передай статус команде и обозначь следующий шаг.

Проверка

Результат должен открываться, повторяться и передаваться следующему человеку без устного пояснения.
